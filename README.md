# C++ Data Structures and Algorithms

This repository contains a collection of common data structures and algorithms implemented in C++. It is intended for educational purposes and as a reference for C++ developers.

## File Descriptions

### Data Structures

*   `LinkedList.h` / `LinkedList.tpp`: A generic singly linked list.
*   `DLinkedList.h` / `DLinkedList.tpp`: A generic doubly linked list.
*   `CyclicLL.h` / `CyclicLL.cpp`: A cyclic linked list.
*   `SeqList.h` / `SeqList.tpp`: A sequential list (array-based).
*   `LinkedStack.h`: A stack implemented using a linked list.
*   `SeqStack.h` / `SeqStack.tpp`: A stack implemented using a sequential list.
*   `LinkedQueue.h`: A queue implemented using a linked list.
*   `SeqQueue.h`: A queue implemented using a sequential list.
*   `LinkedBT.cpp`: A linked binary tree.
*   `SeqBST.cpp`: A sequential binary search tree.

### Algorithms

*   `Eight_Queen.cpp`: A solution to the Eight Queens puzzle.
*   `Infix_Expression_evaluator.cpp`: An evaluator for infix arithmetic expressions.
*   `Infix_to_Suffix.cpp`: A converter from infix to suffix (postfix) notation.
*   `Maze.cpp`: A maze-solving algorithm.
*   `Triangle_Pascal.cpp`: A generator for Pascal's Triangle.

### Classes

*   `AcademicClass.h` / `AcademicClass.cpp`: A simple class representing an academic course.
*   `Polynomial.h` / `Polynomial.cpp`: A class for representing and manipulating polynomials.
